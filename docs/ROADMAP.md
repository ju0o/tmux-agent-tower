# Roadmap

## v0.3.0-rc1

The release candidate brings the existing Tower capabilities into one
user-facing work flow:

- Work Groups and independent task identities.
- Persistent Agent conversations with multiline input.
- Complete-result resolution and one-destination clipboard routing.
- Saved Work and reusable task templates.
- Logical task movement and Live layouts.
- First-run guidance and a user-work default Home.

## Known limitations

- A result is not offered for copying when the Agent's completed-turn
  boundary cannot be established safely.
- Physical remote-client and phone clipboard acceptance depends on the
  connected environment.

## Future candidates

- Additional registered remote Result Providers.
- Broader physical-device acceptance coverage.
